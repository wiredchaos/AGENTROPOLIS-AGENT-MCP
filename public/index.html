Anti-Moloch Controls

Architecture limits exposure. Governance limits failure.

01

Bounded authority

Public tools can route, list, map, and assess. They cannot sign, pay, publish, delete, or self-escalate.

02

Receipt by default

Every tool call records hashes, authority, status, duration, and request identity without storing raw private inputs.

03

Security slowdown

Credential, wallet, urgency, and transaction language triggers warnings before any deeper corridor is considered.
